# Mergejo branding

| File | What it is |
| --- | --- |
| `mergejo-wordmark.svg` | The "Mergejo" wordmark |
| `mergejo-logo.svg` | The "M" mark on its own (launcher, notification and store icons) |

The Android drawables generated from these (`app/src/main/res/drawable/mergejo_wordmark.xml`,
`ic_launcher_foreground.xml` and `ic_stat_mergejo.xml`) are covered by the same terms.
